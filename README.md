# Casa do Príncipe

Aplicativo oficial de gestão e organização do Ilê Axé Omo Aladê – A Casa do Príncipe.

### Funcionalidades

- Agenda
- Eventos
- Membros
- Projetos
- Atividades culturais

- Documentos
- Comunicação
- Calendário
- Ações socioambientais
